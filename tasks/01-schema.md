# Task 1: Project scaffold and schema

**Build order item:** 1
**Status:** todo

## Goal

A `uv` project that installs, and `app/schema.py` holding the Pydantic models
every other file imports. The schema in PROJECT_BRIEF.md is the contract; this
file is a transcription of it, not a redesign.

## Files

- `pyproject.toml` — new. Python 3.12, deps below.
- `uv.lock` — generated by `uv sync`, committed.
- `app/__init__.py`, `evals/__init__.py` — new, empty.
- `app/schema.py` — new. `Status`, `PaymentMethod`, `Extracted[T]`, `LineItem`, `ExpenseDocument`.
- `tests/test_schema.py` — new. The invariant check.

## Steps

1. `uv init`, set `requires-python = ">=3.12"`. Add runtime deps:
   `fastapi`, `uvicorn[standard]`, `python-multipart`, `pydantic`, `openai`,
   `httpx`, `pillow`, `rapidfuzz`. Add `pytest` as a dev dep.
   Leave `pypdfium2` out until multi-page PDFs are actually in scope.
2. Copy the models from PROJECT_BRIEF.md verbatim. Do not add, rename or
   reorder fields.
3. Add a `model_validator` on `Extracted` enforcing the one invariant the brief
   states in a comment: `value is None` unless `status == "present"`.
4. `tests/test_schema.py`: a valid `ExpenseDocument` parses; an `Extracted`
   with `status="not_present"` and a non-null value raises `ValidationError`.

## Done when

- [ ] `uv sync` succeeds and `uv.lock` is committed.
- [ ] `uv run pytest` passes.
- [ ] `ExpenseDocument.model_json_schema()` returns without error — the
      extractor hands this to the model as the structured-output schema.
- [ ] Field names and types match PROJECT_BRIEF.md exactly.

## Out of scope

- Number and date parsing, arithmetic checks, confidence logic — tasks 5/6.
- `pypdfium2` and PDF handling. Images only until the brief's "later" arrives.
- Any ground-truth-shaped model. The scorer reads ground truth as plain dicts.
